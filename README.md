# D-Media

Full-stack news platform built with Node.js and a dependency-free browser client.

## Run locally

```bash
npm start
```

Open `http://localhost:3000`. The server creates `data.json` on first launch and uses it as the local JSON datastore.

## Included

- Responsive home, latest, category, search, featured, and article views
- Reader registration and sign in
- Admin dashboard with create, edit, delete, featured toggle, and image upload support
- JSON-backed HTTP API with no external database or package install required
